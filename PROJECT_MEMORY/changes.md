# Лог изменений проекта

> Append-only. Формат: `[ГГГГ-ММ-ДД] Что сделано (затронутые файлы/части)`.
> Правит этот файл после каждого завершённого изменения.
> Записи до 2026-11-25 удалены при полной очистке каталога.

---

[2026-11-25] Полная очистка каталога и истории репозитория. Удалены устаревшие
модули, тесты, скрипты, PDF, логи, кэши байт-кода и старые записи этого лога.
Git-история пересоздана как один чистый коммит текущего состояния. Файлы:
`PROJECT_MEMORY/changes.md`, `.git/`.

[2026-11-25] Переход на VK как единственный канал. Удалён сервис старого бота из
`docker-compose.yml` и контейнер; код и документация старого канала удалены из
каталога. Текущие сервисы: `postgres`, `redis`, `minio`, `backend`, `vk_bot`,
`celery_worker`. Файлы: `docker-compose.yml`, `.env`, `.env.example`,
`start.bat`, `start.sh`, `README.md`, `backend/`, `bot_vk/`, `celery_worker/`.

[2026-11-25] Веб-админка вместо встроенной панели в мессенджере. `GET /admin`
отдаёт `backend/app/web/admin.html`; вход по `HMAC_SECRET` через заголовок
`x-admin-secret`. Разделы: обзор, клиенты, услуги, записи, работы, настройки.
Экспорты Excel содержат только VK-колонки. Файлы: `backend/app/main.py`,
`backend/app/web/admin.html`, `backend/app/api/v1/admin.py`,
`backend/app/services/*_export.py`.

[2026-11-25] Напоминания и уведомления администратора переведены на VK API.
`celery_worker/tasks.py` отправляет напоминания в две стадии по аккаунтам с
`platform='vk'`; `bot_vk/vk_notify.py` отправляет уведомления о новых записях и
отменах на `ADMIN_VK_ID`. Метки `reminded_at`/`reminded_soon_at` проставляются
только после успешной отправки. Файлы: `celery_worker/tasks.py`,
`bot_vk/vk_notify.py`, `bot_vk/bot.py`, `backend/app/core/config.py`.

[2026-11-24] Добавлена настройка таймзоны сервиса. Часы работы, календарь,
отображение времени и напоминания используют `timezone` из `Setting`; в БД время
хранится в UTC. Файлы: `backend/app/services/schedule.py`, API, боты, воркер,
`README.md`.

[2026-11-24] Статическая сверка клиентского кода с API: вызовы и подписи
совпадают, клиенты склеиваются по телефону, услуги PDR учитываются отдельно при
поиске занятых слотов. Заявки на оценку вмятин в актуальном коде отсутствуют.

[2026-11-26] Очистка Docker-артефактов после перехода на VK. Удалён устаревший
образ старого мессенджер-бота, два остановленных служебных контейнера и связанный
анонимный volume. Образы и контейнеры backend, vk_bot и celery_worker пересобраны
и пересозданы: в окружении больше нет переменных старого канала. Два оставшихся
анонимных volume принадлежат текущему MinIO (`/certs` и `/bitnami/minio/data`) и
используются его контейнером, к старому коду отношения не имеют. Проверено: 6
сервисов Up, образов без тега нет, `/health` и `/admin` отвечают 200, админ-API
без секрета → 403, с `HMAC_SECRET` → 200.

[2026-11-26] Упрощены подписи в веб-админке и шаблоне окружения. Заголовок админки
теперь нейтральный («Запись и учёт автосервиса»), секция VK в `.env.example` без
уточняющей пометки. Файлы: `backend/app/web/admin.html`, `.env.example`.

[2026-11-26] Веб-админка адаптирована для телефонов. На узких экранах таблицы
становятся карточками с подписями полей, вкладки прокручиваются и закрепляются,
кнопки и поля увеличены для касания. Файл: `backend/app/web/admin.html`.
